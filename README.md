# Security Log Analysis & IT Investigation Lab
This repository showcases hands-on log analysis investigations performed using Splunk as part of my cybersecurity and IT learning journey.
This repository contains hands-on investigations using Splunk to analyze system and authentication logs.
The goal of these investigations is to identify normal versus suspicious activity, practice log searching and filtering, and develop troubleshooting and investigation skills used in IT support and security roles.
These exercises simulate real-world scenarios such as login troubleshooting, authentication monitoring, and system activity analysis.

## Hands-On Investigations
- **Investigation 01:** Authentication Analysis
- **Investigation 02:** Failed Login Pattern Analysis
- **Investigation 03:** Session Activity & Successful Login Review
- **Investigation 04:** Windows Authentication Log Investigation
  
## Skills Demonstrated
- Log analysis using Splunk
- SPL search creation and filtering
- Linux authentication log analysis
- Windows security event log analysis
- Identification of failed and successful login patterns
- Session activity investigation
- Evidence collection and documentation
- Troubleshooting authentication and system activity
- SOC-style investigation workflows

## Tools Used
- Splunk
- Windows Security Event Logs
- Linux Authentication Logs
- Search Processing Language (SPL)
